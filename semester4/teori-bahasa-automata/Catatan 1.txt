4. Diberikan dua bahasa:
L1 = {a^n b^n | n 0}
L2 = { w w | w ∈ {a, b}^* }
a) Tentukan kelas hierarki Chomsky dari masing-masing bahasa di atas (Regular, CFG, CSL, atau Recursive Enurable).
b) Berikan argumen mengapa L2 lebih kompleks daripada L1.

2. 
def is_palindrome_stack(s):
    stack = []
    n = len(s)
    if n % 2 != 0:
        return "Rejected"
    for i in range(n // 2):
        stack.append(s[i])
    for i in range(n // 2, n):
        if not stack or stack.pop() != s[i]:
            return "Rejected"
    return "Accepted"

# Contoh penggunaan:
print(is_palindrome_stack("abba"))  # Accepted
print(is_palindrome_stack("abab"))  # Rejected

b) Mengapa L2 lebih kompleks dari L1:
- L1 hanya mencocokkan jumlah a dan b, bisa dilakukan dengan 1 stack (PDA).
- L2 mencocokkan seluruh string w dengan salinan persis w, membutuhkan memori tak terbatas dan pencocokan posisi → butuh Mesin Turing.
- Maka, L2 membutuhkan model komputasi lebih kuat daripada L1.
