🟢 ALUR TOKO BUAH:
- Gunakan array atau ArrayList
- Input pilihan buah dan jumlah
- Tampilkan total bayar

🟢 ALUR TOKO BUKU (DB):
- Buku.java = model
- Koneksi.java = koneksi DB
- BukuDAO.java = insert & select
- Main.java = input data lalu simpan

🟢 Kategori:
- 000 → Informatika
- 200 → Agama
- 800 → Sastra

🟢 SQL TABEL:
CREATE TABLE buku (
 id INT AUTO_INCREMENT PRIMARY KEY,
 judul VARCHAR(100),
 pengarang VARCHAR(100),
 penerbit VARCHAR(100),
 isbn VARCHAR(20),
 kategori VARCHAR(10),
 tempat VARCHAR(50),
 kode_buku VARCHAR(10),
 jumlah INT,
 harga INT
);

Koneksi.java → fungsi getConnection() untuk konek ke MySQL
BukuDAO.java → tambahBuku(), ambilSemua(), updateBuku(), hapusBukuByID()
Main.java → titik awal program
Tabel 'buku':
  id (int, AI), judul, pengarang, penerbit, isbn, kategori, tempat, kode_buku, jumlah, harga
